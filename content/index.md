
Welcome to statistical analysis plan (SAP) assessment for medical device clinical investigations.

This demo site shows the use of RAG retrieval augmented generation (GNO semantic search) and LLM large language model (ChatGPT 5.5) reasoning technologies in assessment of SAPs with emphasis on:
- traceability -> references to sources (line numbers and paragraphs from SAP under assessment and authoritative guidance such as ICH E9)
- transparency -> assessment is build in steps: (question -> question attributes -> SAP assessed against question attributes -> gap statement) to support checking of the correctness of the assessment

Automated SAP assessment presented does NOT remove the need for professional statistical competence but does provide the benefits of:
- comparing SAP to several similar SAPs in the same device category 
- guided systematic assessment of SAP for deeper engagement with SAP content
- automated documented review for each SAP version
See also [[Risks of automated SAP assessment]] such as hallucination.

SAP assessment consists of twenty fundamental [[Questions]] each broken down to [[Question attributes]]. There are [[Trusted sources]] (page work-in-progress).

As an example there four public SAPs assessed. The assessment outcomes can be accessed from the left menu NCT-folders. See statement on [[Fair use]].
